## The 5-Gate Framework (apply to EVERY evaluation)

A role is a **#1-applicant target** only if Husam clears ALL 5 gates AND is top-3% on Gate 4.
Otherwise label it **B-pile fit** in the report. Never blur the two categories.

1. **Gate 1 — ATS/screen-out (binary).** Knockouts: work auth, clearance, language profile,
   education level, literal minimum years, exact-phrase keyword presence, salary band alignment.
   Run Gate 1 BEFORE any tailoring. Federal: read **area of selection FIRST**.
2. **Gate 2 — Recruiter shortlist (6–8s scan).** Most recent title/employer reads same-archetype
   in the top 1/3 of page 1; exact tool names match the JD (Power BI ≠ Tableau); credentials
   recognized (Reliability, IRCC); tenure pattern clean (concurrent roles framed as concurrent);
   visible tailoring.
3. **Gate 3 — Hiring manager A-pile.** Has he done the actual day-to-day? Named tools survivable
   in a technical screen? Stakeholder pattern matched? Artifacts shipped (briefing notes,
   dashboards, SOPs)? Speaks the industry's jargon?
4. **Gate 4 — Differentiation (top 1–3%).** Rare combo the role hints at; on-trend signal
   (AI literacy, automation, evidence-based methodology); friction removed (clearance held,
   available, no relocation); mid-band salary ask; internal/referral credibility.
5. **Gate 5 — Red flags.** No overclaim (every line phone-screen defensible); no trajectory
   mismatch; no hidden essential in the fine print; posting live (not ghost); urgency aligned.

**Scoring overlay:** the standard A–F blocks still run, but the report MUST include an explicit
5-gate table (pass/fail per gate + Gate-4 percentile judgment) and the final label:
`#1-APPLICANT TARGET` or `B-PILE FIT`. Score < 4.0 → recommend against applying.

  asset coverage as X of N (this is the rank differentiator — report it).
- Check: area of selection → language profile (imperative vs non-imperative) → security level →
  education standard → experience essentials, in that order.
- Identify what the posting actually is: acting, assignment, secondment, deployment,
  term, indeterminate appointment, or **pool/inventory**. Flag worthwhile pools even with

  CR-04 ≈ AS-01 ≈ below floor; PM-01 below floor; **PM-02/AS-02/EC-02 straddle the floor at

- Internal IRCC postings: surface aggressively — internal candidate advantage is his single
  strongest Gate-4 lever in the federal stream.
